# Recovery probes across both families: exploratory follow-up

The first experiment's 40-step interval always aligns with parlay curriculum
slots. This follow-up is predeclared after inspecting those results; all fixtures
are already consumed development data, not an independent holdout.

One fixed alternative uses interval 37. At generations 37, 74, 111 and 148,
the existing 10-step curriculum selects SINGLE, PARLAY, PARLAY and SINGLE
respectively. Probe only if the selected family's ordinary action is WAIT, pick
the least-observed action in that family, and retain all actual simulated rewards.
Compare current v3, the prior 40-step candidate and this candidate on the same
three 180-decision fixtures. Preserve all loss/drawdown regressions. Four bounds
the number of scheduled probes, not the normal exploit tickets after a positive
update. A fixed stake cap and independent PaperBook settlement still apply.

This trial does not alter runtime configuration, production memory or the live
agent. Neither synthetic results nor this post-hoc design selection establish
profits, legitimate sporting outcomes, forward evidence or promotion authority.
