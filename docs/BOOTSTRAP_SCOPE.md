# Bootstrap scope

The bootstrap branch establishes only the first canonical spine: repository governance/docs, normalized MarketEvent, current-state projection, causal replay, exact-decimal PaperBook, semantic copyable UI shell, Windows launcher skeleton and cross-platform CI. It intentionally does not pretend to contain provider ingestion, persistent high-rate storage, portfolio solver, forecasting/agents, strategy learning, packaged Windows artifact or human NVDA verification.
