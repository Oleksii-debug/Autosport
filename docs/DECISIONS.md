# Architecture decisions

ADR-001: Autosport is an independent repository/product; no runtime dependency on unfinished Nika-Core.

ADR-002: Whole-product development; versions are release checkpoints.

ADR-003: Market hot path is deterministic and non-LLM.

ADR-004: Live and historical replay feed the same normalized event-stream contract.

ADR-005: Paper ledger and odds arithmetic at ledger boundaries use Decimal.

ADR-006: Portfolio truth is deterministic dependency/scenario mathematics, not LLM memory.

ADR-007: Primary NVDA-readable content must also be visible/selectable/copyable DOM text.

ADR-008: Canonical execution scope excludes autonomous real-money wagering.
