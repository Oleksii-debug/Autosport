# Owner progress format

Use heading `Прогрес Автоспорт`, then one dense paragraph with `Готово зараз`, `Ще не готово`, `Exact evidence`, `Прогрес X%`, and `Наступний найближчий крок`. Avoid long raw CI logs unless requested. The percentage must match `docs/PROGRESS.md` and distinguish provisional branch work from integrated main.
