# Autosport roadmap — versions as release checkpoints, whole-product development throughout

Autosport is not developed as isolated sequential mini-projects. Workstreams run in parallel across the whole program, while each release checkpoint defines the minimum integrated evidence needed to ship a useful Windows build.

## v0.1 — runnable causal paper laboratory

Minimum integrated release: Windows/WebView shell; semantic/copyable keyboard UI; canonical MarketEvent and current-state projection; fixture/file provider; deterministic causal replay with future-outcome isolation; virtual bankroll; single/parlay paper tickets; basic settlement; experiment identity; first strategy/agent boundary; CI on Windows/Linux; early packaged Windows candidate. This is not a throwaway demo: its domain contracts and ledger become the foundation of later releases.

## v0.2 — high-frequency market and portfolio core

Add measured persistent high-rate event history, richer market taxonomy, provider adapter framework, match/selection identity reconciliation, accelerated replay, durable checkpoints/recovery, odds history views, dependency graph, incremental invalidation, committed/open exposure, exact small-case scenario oracle, worst/best P&L and first scalable portfolio search/solver adapters.

## v0.3 — multi-agent intelligence and evaluation lab

Integrate provider-agnostic local/API ModelGateway, durable agent/task runtime, research/forecast/ticket/risk/critic/learning roles, calibrated probabilities, candidate ticket generation, strategy versioning, causal decision records, Brier/log-loss/calibration metrics, walk-forward experiments, reproducible replay campaigns and comparison dashboard.

## v0.4 — optimization, scale and live observation

Scale event ingestion and replay, introduce production benchmark/backpressure thresholds, advanced combinatorial search (dynamic programming/branch-and-bound/dominance pruning/constraint solver adapters/Monte Carlo where appropriate), cancellation/supersession of stale calculations, lawful live-observation provider adapters, long unattended experiments, robust diagnostics, data manifests and hardened restart/recovery.

## v1.0 — stable Windows product

Packaged deterministic Windows release; mature paper/live-analysis workflow; multi-sport extensibility; reproducible datasets and experiments; robust portfolio mathematics; multi-agent orchestration; learning/evaluation; accessible setup and diagnostics; performance/recovery gates; exact release manifest/hash; physical keyboard/NVDA acceptance on the packaged candidate. Real-money autonomous wager execution remains outside canonical implementation scope.

## Parallel workstreams

At any milestone, workers may advance: providers/ingestion; event storage/replay; PaperBook/settlement; portfolio math; forecasting/agents; learning/evaluation; accessible Windows UI; persistence/recovery; performance; packaging/release. Priority is always the shortest current critical path to an integrated usable product, not the numerical version label of an individual file.
