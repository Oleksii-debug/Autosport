# Historical-seeded, prospective shadow challenger

The previously inspected provider-recorded 69-selection price-gap sample produced
+7 units after a 1% cost stress, with wide uncertainty and unverified real fills.
It is a research hypothesis, not proof of profit. Test whether a separate shadow
agent seeded with this historical feedback behaves better on *new* future
opportunities. Do not alter the existing running campaign or its memory.

Seed the standard `ShadowStrategyMemory` from all settled entries in the frozen
`current_rule` cohort of the source-time sensitivity analysis, including every
loss. Use source CSV SHA-256 and the full separately retained journal. The data
were already examined before choosing this challenger; this is not preregistered
training evidence, and observed historical gain is not forward performance.
All historical feedback becomes available only at actual initialization time,
after the source file is read and checked. Require each selected past kickoff
at least 48 hours before initialization, confirmed result/record agreement, and
recorded source time before kickoff. Do not pretend the learner knew these
outcomes at the earlier source timestamp.

Use the existing prospective observer, the same frozen quote/risk-screening
parameters and current 100-observation rolling memory. Seeded feedback is
hypothetical 1-unit net return at recorded source price with 1% cost. New
pre-match observations use the same freeze-then-learn sequence as the unseeded
agent. Start a distinct workspace with its own source evidence, state and memory;
never overwrite or restart the old campaign. Prevent repeat initialization.

Track later outcomes separately from the historical seed and report both chosen
and WAIT decisions. The historical seed is a retrospective, provider-sourced
proxy and its matching rules differ in timing and selection from the live API.
Future recorded prices remain unverified as executable. This challenger has no
real-money, promotion, bookmaker-order or production-risk authority. Do not count
the seed's historic +7 units as money earned or as future experiment results.
