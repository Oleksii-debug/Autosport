# User experience target

The owner should launch Autosport as a Windows application and navigate through normal webpage-like headings and landmarks with NVDA. Main routes expose current experiment/replay status, matches/markets, PaperBook, portfolio scenarios, agents, evaluation and diagnostics. Primary text remains present after announcements so it can be selected/copied. The UI should summarize first and let the user drill into details; rapidly changing markets must not continuously steal focus or flood speech. Notifications are bounded and user-controllable.
