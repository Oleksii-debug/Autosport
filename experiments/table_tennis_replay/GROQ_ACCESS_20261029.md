# Groq: підключення для дослідницьких агентів

Власник надав документ із чотирма профілями. Оригінал збережено на його Google
Drive з доступом лише власника; значення ключів не належать репозиторію.
Локальний файл облікових даних розміщений поза git, каталог має права 0700,
файл — 0600. Він не є частиною Windows-пакета чи конфігурації виробничих агентів.

Призначення зі збереженого документа: профіль 1 — синтез, 2 — критика,
3 — рутинне дослідження, 4 — незалежна оцінка. Це бажані ролі, а не запущені
моделі. Доступність моделей, безплатність та поточні квоти не підтверджені.

`groq_models_probe.py --credentials-file PATH --profile 1` виконує один GET
до офіційного https://api.groq.com/openai/v1/models, без генерацій, повторів,
переадресацій та переходу на інший профіль. PATH має містити JSON з масивом
`keys` у порядку профілів; не зберігати цей файл в git. Інструмент виводить
тільки статус і назви моделей, не текст відповіді з помилкою чи заголовки.

Перевірка 29.10.2026: профіль 1 отримав HTTP 403. Причина не встановлена;
це не доказ недійсності ключа. Генерації, перевірка профілів 2–4, квот та
доступність з Windows не виконані. Три тести пройшли: обмеження відповіді,
відмова від перенаправлення, відсутність секретів у помилках і повторів після 429.

Математична оцінка, зберігання рахунків і контроль фінансових рішень не повинні
залежати від LLM. Groq є додатковим дослідницьким провайдером; зберігаються
режими без LLM та локального Ollama. Цей інструмент не вбудовує провайдера у
виробничий цикл і не надає моделі права робити ставки.

Офіційна документація: https://console.groq.com/docs/openai .
