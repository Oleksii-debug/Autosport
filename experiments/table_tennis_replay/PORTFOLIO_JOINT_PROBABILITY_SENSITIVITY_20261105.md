Досліджено два попередньо переглянуті максимуми відкритих умовних квитків.
[Протокол](https://github.com/Oleksii-debug/Autosport/issues/2591#issuecomment-6650972799)
описано до нового розрахунку. Вхід — 50 записів із того самого
[приватного архіву](https://drive.google.com/file/d/1UMioo0IR37vZpfRtct2IiyBt4QhTTMsn/view),
321 389 байтів, SHA-256
`44508bfa10c57033a671277c949ad5bfd1485744a80211497ad9abe91d3971e9`.
Раніше визначений повтор відкриває 41 умовний PAPER-квиток за записаними
котируваннями, які вважаються заповненими лише для досліду. Це не незалежний
holdout: і дані, і вибрані максимуми вже досліджувалися.

## Припущення і розрахунок

Для кожного точного ID умовно дозволено два взаємовиключні результати —
`home` та `away`. Кожному надано **вигадану**, не оцінену з даних імовірність
0,5. Один і той самий ID має однаковий результат в усіх квитках. Розглянуто
два окремих гіпотетичних спільних розподіли з цими маргіналами:

1. Результати різних точних ID незалежні: усі `2^n` комбінацій рівноімовірні.
2. Є лише дві комбінації: всі `home` або всі `away`, кожна з імовірністю 0,5.

Друге — навмисно крайній приклад залежності, прив'язаний до записаного
орієнтування сторін; він не є виміряною кореляцією чи глобальною межею для
всіх можливих розподілів. Різні ID не доведено різними фізичними матчами.
Якщо ID насправді є псевдонімами одного матчу, незалежна модель та її
простір станів можуть бути неможливими. Нічия, void, повернення ставки та
правила контори не представлені. Понад вісім ID аналіз не обчислюється.

Повторно використано `PaperBook`, `PortfolioEngine`, `ScenarioSearchEngine` та
`analyse_joint_distribution`. Останній перевіряє загальну масу та маргінали,
але не підтверджує авторитетність імовірностей. Для аналізу створено нову
тимчасову книгу з від'єднаних відкритих квитків і довільним достатнім
балансом; це не історичний залишок. Оригінальні квитки не змінюються.
Кожен стан і середній P&L звірено з окремим розрахунком через `Fraction`
за допуском `1e-24 * max(1, |значення|)`; незалежний варіант додатково
звірено з точним перебором `ScenarioSearchEngine`.

## Результати

| Величина | Перший максимум відкритих квитків | Перший максимум спільного точного ID |
| --- | ---: | ---: |
| Відкриті квитки / точні ID | 7 / 8 | 6 / 4 |
| ID з протилежними сторонами у квитках | 0 | 2 |
| Стани: незалежні / всі home чи всі away | 256 / 2 | 16 / 2 |
| Умовна ймовірність програшу **всіх** квитків: незалежні | 29,296875% | 31,25% |
| Те саме: всі home чи всі away | 50% | 0% |
| Умовний середній P&L відкритих квитків: незалежні, од. | −4,24965 | −3,16318 |
| Те саме: всі home чи всі away, од. | −2,39931 | −2,02639 |

Одиниця — умовний розмір ставки повтору. Середній P&L тут відноситься лише
до відкритих квитків за штучно заданими розподілами; попередні результати,
комісії, затримки, void та можливе неприйняття експреса не включені. Це не
реальний результат, не оцінка очікуваного заробітку і не прогноз. У другому
зрізі нульова умовна ймовірність програшу **всіх** квитків не гарантує
позитивний сумарний P&L: виграш деяких квитків може не покрити решту ставок.
[JSON з повною точністю](portfolio_probability_sensitivity_20261105.json)
містить лише агрегати.

## Перевірки та межі

На Linux/Python 3.12 пройшли **648 тестів**, зокрема **10 нових**; один
опційний тест пропущено, бо не задано `TT_TOPSPIN_PARQUET_DIR` з потрібним
читачем і Parquet. `compileall` для `src/autosport` і експериментів TT пройшов.
Перевірено спільну подію, протилежні сторони, різницю між програшем всіх
квитків і від'ємним P&L, порожній зріз, ліміт ID, неприпустимий ринок,
повтор ID у квитку, ставку, примусову розбіжність раціональної перевірки,
хеш входу, незмінність книги й попередніх розрахунків та ізоляцію майбутнього
результату. Базовий повтор і три попередні стреси не змінилися; агрегати
трьох стресів збіглися з раніше опублікованими JSON.

Із перевіреної локальної Python-поверхні 545 файлів збіглися за Git blob-хешем
з батьківським GitHub tree, один змінено та три додано. Серед текстових ключів
і значень публічного агрегату немає точних збігів із 143 різними ID та
іменами з входу; це не доводить загальної анонімності.

Нових джерельних запитів, звірки фізичної ідентичності гравців або матчів,
навчання та реальних ставок не було. Права на навчання, незалежність подій,
доступність і прийняття котирувань не підтверджені; наявний джерельний час
не доводить часу офіційного закінчення чи прийнятої ставки. Стан CI для
точного опублікованого коміту повідомляється окремо в issue.

Для повтору потрібен приватний `LIVE_50_JSON` із зазначеним хешем:

```sh
PYTHONPATH=src:experiments/table_tennis_replay python experiments/table_tennis_replay/portfolio_probability_sensitivity_replay.py LIVE_50_JSON OUTPUT_JSON --expected-sha256 44508bfa10c57033a671277c949ad5bfd1485744a80211497ad9abe91d3971e9
```

Вихід створюється лише якщо файл не існує; сирі записи не публікуються.
