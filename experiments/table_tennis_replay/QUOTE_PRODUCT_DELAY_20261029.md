# Добуток показаних цін експресу між знімками — 29 жовтня 2026

## Питання і метод

Попередній аудит рахував, у скількох парах хоча б одна ціна знизилася, але не
порівнював добуток двох цін. Додано саме це порівняння: для кожної пари
різних ID матчів, у якої **обидві** початкові й наступні ціни придатні,
обчислюється добуток двох початкових та двох наступних цін. Обчислення
використовують точну десяткову арифметику з достатньою точністю для
представлених чисел; це не перевірка фактичної ціни експресу букмекера.

Застосовано незмінне правило вибору та перевірки ринку з
[попереднього аудиту](QUOTE_DELAY_AUDIT_20261029.md): та сама сторона,
дві різні події за ID, та самі ID ринку і виборів, live-фаза, коректний стан
і час перевірки групи ринку. Правило нового порівняння зафіксовано до
обчислення в [задачі №2591](https://github.com/Oleksii-debug/Autosport/issues/2591#issuecomment-6503265359).

Дані вже переглядалися; це описовий аналіз, не нова незалежна перевірка.
Ціни — показані значення із двох знімків, а не прийняті заявки. Не
інтерполюється, що відбувалося між ними. Можливість поєднати вибори,
особи гравців, права на дані й точність годинників не підтверджені.

## Результат на п'яти переходах

| Порівняння умовного добутку | Комбінацій |
| --- | ---: |
| Нижчий у наступному знімку | 283 |
| Не змінився | 31 |
| Вищий у наступному знімку | 226 |
| Разом із двома порівнюваними цінами | 540 |

Із 372 комбінацій, де принаймні одна ціна знизилася, у **89** загальний
добуток залишився незмінним або зріс. Отже, напрям зміни однієї сторони сам
по собі не визначає напрям зміни всього умовного експресу.

Це 540 комбінацій із повторними матчами, а не 540 незалежних ставок. Ті самі
події входять у багато пар, можливі спільні гравці й залежності. Даних
недостатньо для висновку про виконувану ціну, ймовірність виграшу чи
прибутковість. Результати категорій додатково звірені окремим розрахунком із
раціональними дробами `Fraction`; числа збіглися.

## Пізніші результати тих самих ID

Один запит результатів за 29 жовтня отримано о **17:07:06 UTC**: 537 рядків,
із них 531 структурно придатний і шість незавершених. Існуючий
`dated_result_audit.py` знайшов 19 точних ID серед 20 раніше спостережених
live-ID із результатом, що проходить перевірки часу джерела й отримання.
У попередньому запиті було 17 таких ID; усі 17 залишилися, з'явилися ще два.
Це порівняння ID джерела, не підтвердження особи чи офіційного букмекерського
розрахунку. Для одного ID відповідного запису не встановлено; це не означає,
що матч програний або не завершився. Результати стали відомими не раніше
отримання відповіді; оцінку ставок за ними не виконували.

перевірено.

спостережень і заздалегідь зафіксований протокол оцінки затримки, пропущених
